# Bexley Lions Website Plan

## 1. Goal
Create a simple, modern communication website for a high school team or school community to publish updates, announcements, game schedules, and important news in one place.

## 2. Core problem
The school/community currently has no central website for communicating important information. Updates are fragmented across social media, messaging apps, or word of mouth, which makes it harder for students, parents, and staff to stay informed.

## 3. Primary audience
- Students
- Parents and guardians
- School administration
- Coaches and staff
- Community supporters

## 4. Product vision
A public-facing website that looks professional and is easy to maintain, paired with an admin dashboard that lets the school post announcements without technical knowledge.

## 5. MVP scope
### Public-facing pages
- Homepage
- Latest News
- Upcoming Games / Events
- About / Team Overview
- Contact

### Admin capabilities
- Log in securely
- Create a news post
- Create a game-day/event post
- Edit or delete content
- Upload images
- Publish or save as draft

## 6. Site content model
### News posts
- title
- date
- summary
- content
- category
- image
- published status

### Event/game-day posts
- event title
- date/time
- opponent
- location
- type (game, fundraiser, meeting, etc.)
- details
- featured image

## 7. UX objectives
- Clear and fast information discovery
- Mobile-friendly layout
- Easy admin publishing flow
- Strong visual identity for school spirit
- Distinct separation between public site and internal admin tools

## 8. Recommended tech stack
- Frontend: Next.js or a simple static HTML/CSS/JS prototype for validation
- Styling: Tailwind CSS
- Admin backend: Supabase or a lightweight CMS
- Hosting: Vercel

## 9. Prototype validation checklist
The prototype should answer:
- Is the homepage easy to scan?
- Can a user quickly find upcoming games and news?
- Does the admin dashboard feel simple enough for non-technical staff?
- Does the branding feel school-appropriate and professional?
- Is the mobile experience strong?

## 10. Suggested first build order
1. Homepage design
2. News feed and cards
3. Upcoming events/games section
4. Admin dashboard mockup
5. Post creation/edit UX
6. Feedback and iteration

## 11. Recommended next step
Build a clickable prototype and test it with 3–5 users to confirm whether the information architecture and admin workflow feel right before adding deeper functionality.
