# Bexley Lions Implementation Backlog

## Goal
Turn the approved concept into a clear build plan with implementation priorities for the next phase of the project.

## Delivery order

### Phase 1 — Core public site
1. Build and polish the homepage
2. Add a news section with cards
3. Add upcoming events and game-day section
4. Add athletics and about sections
5. Review message, branding, and content clarity

### Phase 2 — Admin workflow
1. Add admin dashboard shell
2. Create post form for news
3. Create event form for game-day updates
4. Add edit and delete actions
5. Add published/draft status

### Phase 3 — Production quality
1. Improve mobile layout and responsiveness
2. Tighten typography and spacing
3. Add consistency across page templates
4. Validate content flows and stakeholder feedback
5. Prepare for final MVP release

## Backlog by priority

### P0 — Required for MVP
- Homepage with school identity and clear navigation
- News listing and detail structure
- Events/game-day listing
- Athletics section
- About section
- Admin dashboard for managing content
- News creation and editing flow
- Event creation and editing flow
- Mobile-friendly layout

### P1 — Important for quality
- Featured stories and highlight banners
- Image handling
- Draft and publish state
- Improved admin preview flow
- Contact and quick links section

### P2 — Future expansion
- Search and filters
- Multi-role permissions
- Photo gallery
- Auto-scheduled posts
- More advanced content management

## Detailed implementation tasks

### Task 1: Homepage design
- Add clear hero section with school branding
- Put navigation in a consistent top bar
- Include key CTA buttons for News and Events
- Add cards for school highlights and featured updates

### Task 2: News system
- Create article card layout
- Add date, category, summary, and title
- Add article detail view or extension page
- Ensure cards feel consistent with the rest of the site

### Task 3: Events system
- Add event cards with date, time, and category
- Include game-day details such as opponent and location
- Show upcoming items on both homepage and events page

### Task 4: Athletics section
- Completed: show sport highlights and a school sports directory
- Completed: include available programs with season, level, and team details
- Include schedule-style information and callouts
- Keep the section aligned with the school identity

### Task 5: About section
- Add school values and mission messaging
- Highlight community involvement and school culture
- Ensure copy feels polished and realistic

### Task 6: Admin dashboard
- Build a content management overview
- Add action buttons for create, edit, and delete
- Show recent posts and event listings
- Keep focus on fast publishing for staff

### Task 7: Content forms
- Add form fields for title, category, date, summary, and content
- Add validation for required content
- Add draft/publish logic
- Keep admin workflow simple and quick

### Task 8: Mobile and polish
- Review stack layout and spacing
- Ensure navigation remains accessible on phones
- Tune typography and button sizes
- Confirm content readability

### Task 9: MVP validation
- Test the homepage at desktop, tablet, and phone widths
- Confirm navigation anchors reach the correct sections
- Check that news and event cards render from the content data
- Review the public flow with 3–5 stakeholders before adding backend complexity

## Definition of ready
A task is ready when:
- the goal is clearly defined
- acceptance criteria are visible
- content needs are understood
- design direction is approved

## Definition of done
A task is done when:
- it is implemented
- it works as expected in the prototype
- it meets the acceptance criteria
- it fits the school brand and product direction

## Recommended sprint sequence
1. Sprint 1: Homepage + news + events
2. Sprint 2: Admin dashboard + content management
3. Sprint 3: Athletics + polish + validation

This is the clean implementation backlog to move into the build phase without overcomplicating the project.
